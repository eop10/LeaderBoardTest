# Прототип v5: мобильная версия для каждой роли

`prototype-v5.html` — единый кликабельный прототип «Лидерборд ТПУ»: мероприятия (предзащита, защита, акселератор), конструктор оценочных листов, приём оценок экспертом, итоги, расписание выступлений, отметки наставников, запись на акселератор и материалы тренеров. Открывается двойным щелчком, работает без интернета. Первая загрузка занимает несколько секунд.

## Демо-панель (сверху, не часть продукта)
- Роль: организатор (Петрова Анна, она же эксперт), студент Иванов М., наставники Петров А. С. и Соколова Е. В., тренер Орлов И. А.
- «Сегодня в прототипе» — любая дата.
- «Сеть»: норма / загрузка / ошибка / нет связи.
- «Ширина окна»: 1440 px / 390 px. Экраны организатора на 390 px заменены заглушкой.
- «Открыть чужой раздел» — показывает «Нет доступа».
- «Сбросить демо» — исходные данные; «Сбросить без мероприятий» — пустой список.
- Слева телефон (390 px) с мобильной версией выбранной роли: студент, наставники и тренер видят свой кабинет. У организатора в телефоне экран эксперта Петровой А. (организатор работает с компьютера). Справа компьютер той же роли.
- Телефон и компьютер студента, наставника и тренера повторяют друг друга: действие в одном окне (переход, диалог, запись) сразу видно в другом. Данные общие для всех ролей.

## Сценарии
- А. Организатор → «Мероприятия» → «Создать мероприятие» → Предзащита → «Через расписание»; лист, проходной балл, аудитории, эксперты → «Опубликовать» → «Расписание» (команды, сетка, отметки, «Построить», «Опубликовать») → «Открыть приём оценок».
- Б. Телефон эксперта: оценить команду, «Отправить»; другой — «Не явилась».
- В. Организатор: «Завершить», итоги → «Создать защиту» (только прошедшие, без аудиторий).
- Г. «Создать мероприятие» → Акселератор, направления и тренеры, лимит мест → «Опубликовать». Студент: запись, смена направления, «Имитировать: место заняли». Тренер: загрузка после даты мероприятия.
- Д. Наставник → «Расписание»: отметки до лимита 40 минут.

## Ограничения
- Расписание одновременно только у одного мероприятия. Для новой предзащиты с расписанием сначала «Сбросить без мероприятий».
- «Нет связи» блокирует сохранение только на экранах расписания; телефон эксперта на переключатель «Сеть» не реагирует.

## Состав
- `prototype-v5.html` — офлайн-версия.
- `source/` — исходники: `Прототип v5.dc.html`, `ТелефонV5.dc.html` (копия основного файла для телефона), `МодульРасписанияV5.dc.html`, `support.js` (в одной папке).
