# Прототип · мероприятия, оценки, акселераторы

## Запуск
- Самый простой способ: открыть `index.html` двойным кликом. Это собранная версия, в неё уже встроено всё нужное.
- Через localhost: в этой папке выполнить `python3 -m http.server 8000` (или `npx serve`) и открыть http://localhost:8000

## Что внутри
- Слева — телефон эксперта (ауд. 301), справа — окно выбранной роли: Организатор / Студент / Тренер.
- Переключатель «Сегодня в прототипе» (16 октября / 10 ноября) показывает состояния до и после акселератора «Старт в ИТ»: материалы направления у студента, загрузка презентаций у тренера.
- Данные общие для всех окон. После перезагрузки страницы состояние сбрасывается.

## Файлы
- `index.html` — собранный автономный файл (для показа и запуска).
- `source/prototype.dc.html` — исходник: разметка, стили и вся логика (класс `Component` в конце файла).
- `source/support.js` — рантайм, который рендерит исходник. Без него `prototype.dc.html` не откроется.

Чтобы запустить исходник, откройте через сервер папку `source/` и перейдите на http://localhost:8000/prototype.dc.html

Шрифты (Hanken Grotesk, Manrope, Material Symbols) подключаются из Google Fonts. Без интернета вместо них будут системные шрифты, а иконки покажутся текстом.

## Данные
Начальные данные задаются в методе `seed()`: листы, мероприятия всех трёх типов, команды, эксперты, оценки, направления и тренеры.
