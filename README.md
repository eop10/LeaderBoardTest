# Прототип v2 · расписание выступлений и запись на акселератор

## Запуск
Откройте `prototype-v2.html` двойным щелчком. Файл самодостаточный: работает офлайн, все данные в памяти страницы. «Сбросить демо» в демо-панели возвращает исходные данные.

## Демо-панель (не часть продукта)
- Роль: студент Иванов М. / наставник Петров А. С. / наставник Соколова Е. В. / организатор (Ковалёва Н. А., у неё есть и своя команда как у наставника).
- Акселератор: не открыто / открыто / закрыто.
- Сейчас: до дедлайна / после дедлайна / день мероприятия.
- Сеть: норма / сбой сервера / нет связи — для состояний «ошибка» и «нет связи».
- «Имитировать: место заняли», «Сбросить демо».

## Сценарий «48 из 50»
1. Роль «Организатор» → Мероприятия → Предзащита, осень 2026 → Расписание.
2. Шаг 1: «Подтянуть команды» → «Добавить». «Навигатор по стипендиям» → ауд. 301, «Портфолио выпускника» → ауд. 303.
3. Шаг 3: «Открыть сбор отметок».
4. Шаг 2: в ауд. 303 конец кофебрейка 13:50 (слотов 15, команд 17).
5. Шаг 3: «Построить» (seed 183726) → «Поставлено 48 из 50, не поставлено 2», «Не хватает 2 слотов».
6. «Добавить слоты» → все 50 поставлены → «Опубликовать».
7. Роль «Студент» или «Наставник Петров А. С.»: «Умный кампус» — 12:00–12:15, выступление № 7, ауд. 301.
